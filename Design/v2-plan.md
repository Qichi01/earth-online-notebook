# v2 优化迭代计划（草案）

## 目标
- 在不破坏 v1 稳定性的前提下，优先推进“成就可视化增强”。
- 地图模块延后到成就视觉体系稳定后再进入开发。

## 范围（按优先级）
1. 成就可视化 MVP
- 成就分类系统：如厨艺系、行动系、社交系、探索系、专注系、休整系、成长系。
- 徽章系统：每个成就类型配置 1～3 枚徽章，按累计记录次数解锁，不是每条成就都单独发徽章。
- 成就卡视觉化：日记页的“成就卡”从纯文字升级为“文本 + 图案化设计”卡片，图案根据成就内容与标签生成。

2. 徽章展示与归档
- 角色页新增“徽章柜”。
- 徽章按类型去重展示，保留解锁层级。
- 后续可补充完整“成就图鉴”页。

3. 地图模块（后置）
- 在成就视觉体系稳定后，再进入地图 MVP（2.5D / 轻 3D）。

## 技术建议
- 成就视觉层优先使用纯前端方案：SVG + CSS + Tailwind。
- 图案设计先做“规则生成”，不在 v2 初期依赖文生图能力。
- AI 输出继续提供 tags，前端基于 tags / 标题 / 描述推断成就类型与视觉元素。

## 数据与接口准备
- 增强 achievement tags 的可视化约束，提高前端图案生成稳定性。
- 成就分类与徽章规则优先做前端派生，不强依赖数据库迁移。
- 后续若需要跨端一致展示，再将 category / badge_tier 固化入表。

## 分阶段里程碑
- v2.0：成就分类 + 徽章柜 + 图案化成就卡。
- v2.1：预置成就库与固定徽章素材映射。
- v2.2：成就图鉴页。
- v2.3：地图模块启动。
